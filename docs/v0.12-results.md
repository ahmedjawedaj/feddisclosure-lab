# FedDisclosure Lab v0.12.0 — Native Flower Docker implementation result

Date: 2026-11-20. All metrics below are **observed within the local tool
runtime** unless explicitly described as code/static checks.

## New implementation

Eight-process Docker deployment topology (SuperLink, separate ServerApp
executor, three SuperNodes, three ClientApp executors); optional one-shot CLI
container; pinned Flower 1.27.0 images, CPU PyTorch image, strict build context;
per-site read-only mounts, unique site signatures and identity validation;
training/evaluation receipts, native `docker inspect` inspection, evidence
runner, strict deployment-only model checkpoint parity, and two GitHub CI
workflows updated to insist on the true Flower Deployment Runtime.

## Locally executed evidence

- New public-digit partition preparation: **3 distinct** immutable client
  training and validation NPZ files, one separately retained evaluator cohort.
  Manifest integrity and distinct record indices checked. Source cohort:
  scikit-learn 8x8 digits, 600 sampled records, IID, seed 20261118.
- Source Compose topology checker: **passed**, but only parses configuration.
- Fast regression suite: **122 passed, 2 skipped, 3 slow deselected**.
  Skips were Flower and OpenDP unavailable in this execution environment.
- Independent-worker slow PyTorch tests: **IID 1 passed**, **non-IID 1 passed**
  after one interrupted non-IID attempt was explicitly rerun.
- Fresh two-round three-worker PyTorch reference on the staged Docker dataset:
  global public-digit test accuracy **0.20833333333333334**, checkpoint SHA256
  `5ae8fe93cc5f5dd73b32016f60016c1ba445aba5cbb31005d9ff96397e391fff`.
  **This is NOT Flower or Docker training.**
- Four-process local federated analytics HTTP regression: passed with original
  `110 - 107 = 3` naive leak and refusal of the second history-protected query.
- Native Docker attempt: **BLOCKED, exit code 2**, error `Docker CLI missing`.
  Thus **no native Flower nodes, client receipts, or numerical Flower parity
  have actually executed**.

- CI run ID and retained hosted logs from an actual Docker-capable runner.
- Native privacy library and upstream cryptographic SecAgg+ experiments (not
