# v0.6 experiment protocol and predeclared comparisons

**Date:** 2026-11-19. All datasets are approved public sklearn 8×8 digits. All training and attack runs here are separate-process/local PyTorch, **not native Flower**. Native Docker, Opacus, OpenDP and Flower SecAgg+ are pending.

## E1: Changing SGD minibatches and individual-update leakage

**Observer:** unprotected coordinator receives an individual-client model delta, initial weights, learning rate and number of SGD steps. It does **not** observe intermediate gradients, sample indices, original images or minibatch order. **Extra privilege:** all labels are revealed when reconstructing multiple images.

**Hypothesis:** multi-step disjoint minibatch updates will be less well approximated by the initial full-data gradient and will reconstruct worse under a fixed gradient-matching attack budget.

**Pilot:** One public-digit client partition; data seed 241; minibatch-size 8; cases (steps 1, order 0), (steps 4, order 0), (steps 4, order 1). Each record contributes once. Four-step cases contain **32** distinct examples; one-step case contains **8**. The attack sees the same number of reconstructed target images as the unique records. 160 Adam attack iterations, with privileged Hungarian evaluator assignment. This is a **different sample-count and compute-budget condition**, so conclusions cannot isolate step count alone. The paired four-step schedule variants have matched examples/optimizer budget.

**Metrics:** evaluator-assigned mean image MSE, PSNR, SSIM, relative L2 difference between model-delta proxy and exact initial full-record gradient. `reports/results/sprint3/changing_minibatches/seed241/`.

**Limits:** no OS-enforced separation, no native Flower, no DP or SecAgg+. The attacker is unrealistically provided all labels. The score is evaluator-reassigned, not the attacker's known image matching.

## E2: Output-only model membership leakage across independently trained models

**Observer:** external model user sees only query softmax vectors, **not** labels, model weights, training indices, or membership indicators. Evaluator uses class-matched balanced public training/held-out data queries. Training seeds 241, 242, 243 correspond to the executed 4-round FedAvg checkpoints from the prior paired benchmark; query seed per model = training seed + 1000, per-class target 6.

**Predeclared attack scores:** maximum probability, negative predictive entropy, top-two probability margin. Higher score means 'more likely member'. No method selection on evaluation results. Three models × three methods = 9 ROC evaluations. Report ROC-AUC, advantage, empirical TPR@FPR 1%, 5%, 10%, and between-model spread. Three training seeds do not justify statistical conclusions.

**Limits:** this is offline prediction replay, not a live inference API. Confidence access and balanced membership prior are strong modeling assumptions. A near-chance AUC is not a formal guarantee of privacy.

## E3: Model utility and worst-client behavior

**Observer:** coordinator gets client model arrays and scalar metrics; separate evaluator scores public held-out test and per-site validation. Three independent workers, seed 241, severe non-IID 900 sampled records, 8 communication rounds, 2 local epochs, batch 32, SGD learning rate 0.15. FedAvg and FedProx (mu=0.3) are matched on initial weights, partition, per-round optimizer budget and sampled data. These extend previously executed 4-round runs; first four round accuracy trajectories should match exactly.

**Optional third distribution:** class-conditional Dirichlet(alpha=0.5) on the same source seed/sample/test holdout, with potentially *unequal site sizes and optimizer steps*. Treat this as an exploratory distribution sensitivity result, not fully compute-matched to severe label skew.

**Metrics:** global held-out accuracy per round, worst-client accuracy using final global model, individual site validation, sample sizes and communicated raw tensor bytes (not protocol overhead). Do not claim convergence from 8 rounds or transfer findings to MNIST.

## Native integration gates

Flower 1.27 Python 3.12 ServerApp/ClientApp run is **not executed here** due unavailable `flwr` package and package networking. `.github/workflows/flower-smoke.yml` now includes an actual matched PyTorch reference run and `scripts/verify_flower_parity.py`, comparing every final model tensor. A passing offline parity *fixture test* does not count as native Flower verification. Docker gate remains separately required.

## Executed v0.6 observations (not pre-registration)

- **E1:** For 160 attack iterations, 8 distinct images/1 SGD step/order0 yielded MSE 0.0149083 and gradient-proxy relative L2 error 4.08e-7. With 32 images/4 disjoint SGD steps/order0: MSE 0.0756175, proxy error 0.319507. With the same 32 images and a different order1: MSE 0.0794448, proxy error 0.295576. The 8-vs-32 record count difference is confounded with steps and cannot isolate either. The paired order ablation is matched on target records and optimizer work, but is one data seed only.
- **E2:** Three independently trained models (seeds 241–243), one class-matched query subset per model; mean ROC-AUC: max confidence 0.5422, negative entropy 0.5435, top-two margin 0.5198 (rounded). One top-two margin case <0.5. No strong membership attack was demonstrated; report all individual observations in `reports/results/sprint3/membership_training_seeds/`.
- **E3:** 8-round severe label skew FedAvg seed241 held-out accuracy 0.633333, worst-client validation 0.0625. Matching FedProx mu0.3 run: held-out accuracy 0.605556, worst-client validation 0.0. First four rounds of both runs reproduce the older four-round seeds exactly. With Dirichlet(alpha=0.5) on the same 900 sampled public digits and identical public test cohort, 8-round FedAvg held-out accuracy was 0.827778 and worst-client validation 0.795918. **Not optimizer-matched:** Dirichlet train sample counts were 133/244/200 compared with 192/192/192 in the severe-sorted setup. This comparison is a hypothesis generator, not a causal effect size or multiple-seed result.
- **E4 tooling:** A checkpoint-by-checkpoint Flower-versus-reference numerical parity checker with fail-closed tolerance/config/hash tests is implemented and CI-wired, but **the native Flower and Docker gates were not executed** on the local runtime.
