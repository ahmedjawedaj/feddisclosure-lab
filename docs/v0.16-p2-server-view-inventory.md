## Rule for this inventory

A guarantee holds only for what it covers. For every channel the server can observe, this file states one of three things.

1. **Covered.** The mechanism's guarantee applies to this channel under stated assumptions.
2. **Not covered.** The mechanism says nothing about this channel.
3. **Not examined.** We have not looked.

A channel marked not covered is a candidate for one measured inference. It is not a claim that the channel leaks anything. Evidence level is also stated: source reading, measured, or not examined.

## Assumptions of each protection

| Protection | Assumed server | What it hides | What it does not mention |
|---|---|---|---|
| SecAgg+ | Honest but curious, bounded dropouts, threshold set by configuration | Each client's masked array content until enough shares are revealed | Which clients took part, what is sent outside the arrays, message sizes and timing |
| Central DP, fixed clipping | Server is the trusted party that adds the noise | The released aggregate with respect to one client's update, per round, under zero-out reading | The release decision, the participant set, anything the server sees before noising |
| `LocalDpMod` | Server not trusted | The client's released update with respect to replace-one on the clipped update | Anything outside the update, including participation |

## Predictions to pre-register before any measurement

Written now so that they cannot be adjusted after the data.

| Row | Statement | Detection power needed |
|---|---|---|
| S4 | A client's fit metrics returned under SecAgg+ are visible to the server in a run of the real strategy | Exact. A single run shows or does not show the record |
| S6 | If a client's participation depends on its clipped update norm, the released-or-not bit and the participant set predict that norm above chance | Threshold test over 2,000 rounds, Wilson interval on accuracy, chance level 0.5 |
| S6b | The same dependence changes the effective noise multiplier by the factor of row C4 and the exact epsilon follows from `gauss_eps` | Exact from the harness |

S6 is a hypothesis, not a finding. If the predictions fail, they are recorded as failed.

Update 2026-11-26, release 0.16.13: the three rows were run as pre-registered and none failed. S6 is still a conditional statement. It shows what the server observes if participation depends on the norm, and does not show that any client does so.

## What this does not show

1. Nothing here says the channels leak anything in a real deployment.
2. An active server is outside the stated assumptions of SecAgg+ and central DP. Channel 7 is listed so the boundary is visible.
3. The inventory is for one framework and one configuration.
