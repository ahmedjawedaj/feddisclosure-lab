## Rule for this inventory

A guarantee holds only for what it covers. For every channel the server can observe, this file states one of three things.

1. **Covered.** The mechanism's guarantee applies to this channel under stated assumptions.
2. **Not covered.** The mechanism says nothing about this channel.
3. **Not examined.** We have not looked.

A channel marked not covered is a candidate for one measured inference. It is not a claim that the channel leaks anything. Evidence level is also stated: source reading, measured, or not examined.

## Assumptions of each protection

| Protection | Assumed server | What it hides | What it does not mention |
|---|---|---|---|
| SecAgg+ | Honest but curious, bounded dropouts, threshold set by configuration | Each client's masked array content until enough shares are revealed | Which clients took part, what is sent outside the arrays, message sizes and timing |
| Central DP, fixed clipping | Server is the trusted party that adds the noise | The released aggregate with respect to one client's update, per round, under zero-out reading | The release decision, the participant set, anything the server sees before noising |
| `LocalDpMod` | Server not trusted | The client's released update with respect to replace-one on the clipped update | Anything outside the update, including participation |
