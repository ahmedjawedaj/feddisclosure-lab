# FedDisclosure Lab v0.6.0 — Research engineering report

**Date:** 19 November 2026. This is an intermediate pilot report, not a peer-reviewed publication or thesis novelty claim. Use `docs/v0.6-experiment-protocol.md` for predeclared threat models and explicit confounders.

## Executive findings

1. **Unprotected individual-client updates can permit reconstruction** when the attacker knows the full model, hyperparameters, and all contributing labels. With eight distinct public-digit records after one SGD step (160 iterations), evaluator-assigned MSE was 0.01491. With 32 unique examples across four disjoint minibatches (same iteration budget), MSE increased to 0.07562 and 0.07944 for two batch orders. Four-step order variants share the exact data and compute budget. The initial-gradient proxy differs materially after local steps.
2. **Output-only membership inference was weak** on three independently trained four-round public-digit FedAvg checkpoints. The mean ROC-AUC across these *model seeds* was approximately 0.542 (maximum confidence), 0.543 (negative entropy), 0.520 (top-two margin). All 9 attack results, low-FPR operating points and failures are in the evidence archive. AUC~0.5 does not establish a formal guarantee.
3. **Longer training helps but severe label skew can still break worst-client utility.** FedAvg severe skew improved held-out accuracy from 51.11% after 4 rounds to 63.33% after 8 rounds for seed241, but worst-client global-model validation remained 6.25%. Matched FedProx mu0.3 after 8 rounds achieved 60.56% global and 0% worst-client. The first four rounds of both 8-round results exactly match earlier saved trajectories.
4. **Moderate Dirichlet partitioning changes the utility picture.** On the same seed241 source subset and public test cohort, 8-round FedAvg global accuracy reached 82.78% with 79.59% worst-client validation. Importantly, the site sample sizes (and optimizer steps) differ from the severe skew setup. One seed is not a controlled causal estimate. A fixed-size, multiple-seed ablation is necessary.
5. **Native protocols remain an outstanding gate.** Docker Engine and Flower cannot run here, so there are no Flower/SecAgg+ results. The new parity validator only becomes scientific native evidence when Flower actually executes on an appropriate Python3.12 environment and passes layer-wise comparison with a matched reference.

## Reproduction and integrity

1. Install locally with `python -m pip install -e '.[research,test]'` when network permits. Existing environment used `--no-build-isolation --no-deps` after prerequisites were preinstalled.
2. Run `pytest -q -m 'not slow'`, each marked-slow integration test separately, and `python scripts/run_local_stack.py --once`.
3. On the *full release bundle* (not a Git source checkout, which excludes raw research artifacts), execute `python scripts/verify_research_evidence.py`, `python scripts/verify_v060_evidence.py`, `python scripts/plot_minibatch.py`, and `python scripts/plot_extended_training.py`.
4. A Flower-enabled machine must execute `python scripts/run_flower_experiment.py` and `python scripts/verify_flower_parity.py` for protocol claims. Docker requires `bash scripts/verify_compose.sh` on a real daemon.
5. Re-run individual experiments only in clean output directories; scripts refuse existing evidence to avoid overwrites.

## Next falsifiable research questions

- With matched per-site sample counts and optimizer updates, does Dirichlet severity predict worst-client utility across at least five independent seeds?
- Under what sample/label-budget conditions does model-delta inversion succeed without the all-label oracle? Can an attacker infer labels or only detect aggregate properties?
- How do formal DP-SGD and SecAgg+ change what an honest-but-curious observer actually receives, and what utility/communication budget is paid?
- Can a well-trained but calibrated output-only model show membership signals reliably at 1% FPR under a realistic query budget?

## Limitations

Public sklearn digits only, CPU MLP, one pilot seed for extended training and gradient inversion, small samples, no established DP or secure aggregation, no native Flower/Docker run, no OS-enforced attacker/evaluator isolation, no clinical relevance claim, and no validated digital twin.
