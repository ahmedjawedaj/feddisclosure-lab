# FedDisclosure Lab v0.9.0 — research and delivery report

## Hypotheses, observer and data

H1 (exploratory): A joint inversion that matches all contributors to an aggregate observation can recover information that a target-only aggregate proxy misses.

The three simulated institution clients have separate public 8×8 digit partitions. Each computes one full-batch SGD update over 8 images from a common initialized MLP. The evaluator/setup process forms the arithmetic mean. **This is not cryptographic secure aggregation.** The joint attacker receives the aggregate update, model weights, learning rate, and all **24 true class labels grouped by institution**. The original images, per-client updates and raw rows remain outside attacker inputs. Grouping labels by institution is an extra privilege: it is not a normal encrypted aggregate release and may reveal class membership by institution. The attacker does not receive original image pixels.

The gradient-matching attacker jointly optimizes 24 dummy images for 160 iterations. A separate evaluator performs label-constrained optimal assignment. Its `target_oracle_label_matched_mse` can choose a best match across all 24 recovered candidates and is **not an attacker site-attribution method**. The experiment was not a paired comparison under equal label privileges to v0.8's target-only proxy.

Mean pooled MSE ~0.057316. All three saved attack observations, recovered arrays, scoring files, and summary hashes passed read-only verification. The joint aggregate update's exact gradient proxy matched its full pooled gradient within approximately 4e-8 absolute error. Stochastic multi-seed estimates are descriptive; three seeds and one model/optimizer design are not enough for broad claims.

`python scripts/verify_joint_aggregate.py` recomputes evaluator metrics without calling the attacker.

## Paired federated training inference: five matched seeds

Exploratory reporting contrast selected in v0.9 after the v0.7 benchmark: balanced Dirichlet alpha 0.1 minus IID. This is not preregistered confirmatory inference. Three clients, equal-size local train/validation data, equal local optimizer batches, four rounds, and matched seed/test cohort. The 20 source experiment runs were performed in v0.7; v0.9 adds uncertainty calculation, not new training.

| Outcome | Mean paired difference | 95% paired t interval | Exact sign-flip p |
|---|---:|---:|---:|
| Global test accuracy | +2.33 percentage points | −1.73 to +6.40 pp | 0.375 |
| Worst-client validation | −11.67 percentage points | −36.38 to +13.05 pp | 0.4375 |

Both intervals include zero. **No statistical significance or causal claim** is justified. With five paired seeds the sign-flip test has low resolution. The t interval assumes sufficiently approximately normal independent paired differences; no multiplicity correction or confirmatory preregistration is asserted.

`python scripts/analyze_balanced_study.py` recomputes the report from saved five-seed inputs.

## Interactive evidence explorer

`python -m dashboard.build_dashboard` creates an offline `dashboard/dist/index.html` and `evidence_snapshot.json`. It reads only three whitelisted original scalar summaries plus finished joint-oracle summary files, embeds no raw images, model deltas, or train/validation records, and has tabbed charts for model utility, aggregate reconstruction, membership ROC-AUC and native-verification status. The output needs no server or internet connection. The optional `streamlit run dashboard/app.py` source is available for a Python 3.12 host with the `[visual]` dependencies. Streamlit was not installed/executed here.

## Verification and blockers

The v0.9 fast suite passed 88 tests with two optional native-library skips and three deselected slow tests. Additional independent attack/evaluator tests and evidence hash checks pass. No native Docker Engine, Flower, OpenDP, Opacus or Flower SecAgg+ is present; package-index DNS resolution fails. No native DP or cryptographic protection claim can be made. Docker and Flower source/workflows remain prepared for a future network-enabled runner.

The existing archive still stores public images in researcher/evaluator evidence folders for benchmark reproduction. These folders are **not OS permission isolation** and should not be mounted into attacker containers.

## Scientific next action

Native defense execution is now the primary publication blocker. A better aggregate attack and a polished explorer are useful engineering outputs, but do not replace matched formally private release experiments, real Flower protocol runs, external dataset replication, and manuscript novelty review.
