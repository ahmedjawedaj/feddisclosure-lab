# OpenDP count/release control review skill

Read `docs/opendp-runtime.md` and `docs/v0.7-pre-registered-protocol.md`. Never substitute a hand-rolled noise generator or fake test mechanism for native OpenDP evidence. Threat model is an external authorized analytics user, not the site database admin. Add/remove adjacency and per-record count sensitivity 1 are explicit; protected release omits raw-dependent cell suppression. Budget scope is independent of experiment ID, stored in site-local SQLite with atomic BEGIN IMMEDIATE; reject restarts that downgrade a spent DP database or switch a dataset with previous unprotected query audit. In DP-only mode, no raw endpoint is allowed. Gateway must not leak partial noisy values on refusal. DP accounting and privacy-map tests must execute with actual OpenDP installed before claiming any epsilon guarantee. The same safeguards do not constitute Opacus DP-SGD or secure aggregation.
